# Cyber Group — корпоративный сайт компании

## Описание проекта
Корпоративный сайт компании «Cyber Group». Разрабатывался в рамках производственной практики (июль 2026) как замена устаревшего сайта. 

**Задача:** создать современный, адаптивный и функциональный сайт, отражающий деятельность компании в сфере информационных технологий и кибербезопасности.

## Мой вклад в проект
В составе команды разработчиков участвовала в создании нового сайта. В зону моей ответственности входила вёрстка следующих разделов:

- **Раздел «Партнеры»** — карточки компаний-партнёров с логотипами, описанием и ссылками
- **Раздел «Проекты»** — портфолио выполненных работ с фильтрацией по категориям

**Что именно делала:**
- Вёрстка макетов по ТЗ (HTML, CSS)
- Адаптация под мобильные устройства и планшеты
- Проверка кроссбраузерной совместимости
- Участие в код-ревью и обсуждении архитектуры разделов
- Взаимодействие с бэкенд-разработчиками для интеграции данных

## Технологии
- HTML5
- CSS3 (Flexbox, Grid)
- JavaScript (базовые интерактивные элементы)
- Git / GitHub (совместная работа)

## Командная работа
- Работа в команде из 4 человек над проектом по разработке сайта для компании «Cyber Group».
- Выполняла вёрстку закреплённых за мной разделов («Партнеры» и «Проекты») с использованием HTML и CSS.
- Использование **Git** для ветвления и слияния кода

## Результат
Сайт успешно сдан в эксплуатацию. Мои разделы прошли проверку QA-инженера без критических замечаний.
